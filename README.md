# Chez Lucie — redirection du domaine nu

Ce dépôt public ne contient que la redirection HTTPS permanente de
`chezlucie.fr` vers `https://www.chezlucie.fr`. Vercel conserve le chemin et
les paramètres de requête. Le code et les données du site principal restent
dans leur dépôt privé.

La zone OVH du domaine nu utilise les deux enregistrements A recommandés par
Vercel (`216.198.79.1` et `64.29.17.1`). Le sous-domaine `www` reste relié au
site principal et les enregistrements de messagerie sont indépendants.
